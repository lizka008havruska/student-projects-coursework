# Сценарій демонстрації (8–10 хвилин)

## Підготовка (до захисту)
1. MySQL і Apache запущені; у phpMyAdmin імпортовано `database.sql` (чисті демо-дані).
2. `cd server && mvn clean test && mvn clean package`; WAR скопійовано в `webapps` Tomcat 9; Tomcat запущений.
3. У браузері відкривається `http://localhost:8080/student-projects-server/students`.
4. `cd client && mvn javafx:run`.

## Контрольні дані (після чистого `database.sql`)
| Таблиця | Записів | Примітки |
| --- | --- | --- |
| student | 3 | id 1–3 |
| project | 3 | id 1–3 |
| submission | 4 | №1 ПРИЙНЯТО I=86,80; №2 ПЕРЕВІРКА I=62,20; №3 ПОДАНО I=29,50; №4 ЧЕРНЕТКА I=0 |
| review | 2 | до подань №1 і №2 |

## Хід демонстрації
1. **Структура і GitHub (1 хв).** Репозиторій, commit за етапами, README, tag `coursework-final`.
2. **Тести (1 хв).** `mvn clean test` у `server`: 30 тестів, Failures 0, Errors 0.
3. **Сервер (1 хв).** Tomcat, GET `/submissions` у браузері (JSON).
4. **CRUD (2 хв).** Вкладка «Студенти»: додати `Тестов Тест`, змінити групу, видалити. У phpMyAdmin
   оновити таблицю `student` — зміни видно в MySQL.
5. **Життєвий цикл (2 хв).** Вкладка «Подання», подання №4:
   - ПРИЙНЯТО одразу → помилка про недопустимий перехід (стан у БД не змінився);
   - вказати репозиторій `https://github.com/test/repo` → «Змінити» → ПОДАНО → ПЕРЕВІРКА;
   - ПРИЙНЯТО без рецензії → помилка «лише за наявності рецензії».
6. **Показник (1 хв).** Подання №2: F1=70, F3=50 → «Виставити F1 і F3»: F2=62, I=62,20.
   Вкладка «Рецензії»: додати до №2 оцінку 80 → F2=71, I=65,35 (0,40·70 + 0,35·71 + 0,25·50).
7. **CSV-імпорт (2 хв).** Вкладка «Проєкти»:
   - `sample-data/projects.csv` → імпортовано 8, пропущено 0; ProgressBar рухається, інтерфейс доступний;
   - той самий файл ще раз → імпортовано 0, пропущено 8 (назви вже існують);
   - `sample-data/projects_errors.csv` → імпортовано 2, пропущено 4 (рядки 3, 4, 5, 6 із причинами);
   - `sample-data/projects_bad_header.csv` → помилка заголовка;
   - неіснуючий файл → повідомлення «CSV-файл не знайдено».
8. **Журнал (за потреби).** Консоль Tomcat (INFO/WARNING) і консоль клієнта (рядки імпорту).

## Після демонстрації
Для повернення чистих даних знову імпортувати `database.sql`.
